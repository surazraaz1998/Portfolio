# Suraj Raj — Senior Full Stack Developer Portfolio & Interactive 3D Journey Game

An interactive, production-grade personal portfolio website and 3D side-scrolling career journey game built for **Suraj Raj** (Senior Full Stack Developer with 5+ years of experience specializing in React, Next.js 14, TypeScript, and Python FastAPI).

---

## 🚀 Key Features

- **Interactive 3D Career Journey Game**: Built with **React Three Fiber (R3F)**, **Three.js**, **Zustand**, and **Framer Motion**. Features a custom 3D running cartoon avatar exploring milestone zones across Capgemini, Newgen, GetMyParking, and Gramener (Warner Bros. Discovery).
- **Recruiter-Optimized UX**: Instant switching between interactive game view and traditional responsive resume view.
- **Dedicated Resume Viewer Page (`/resume`)**: Embedded PDF viewer with instant one-click PDF download and fullscreen raw PDF view.
- **Academic Foundation Section**: Dedicated Education component highlighting B.Tech in Computer Science from Lovely Professional University.
- **Technical Skills & Capability Radar**: Interactive category breakdown and Recharts Radar visualization.
- **High-Performance Web Design**: Dark mode aesthetic, glassmorphism UI, custom scrollbars, and sub-100ms API design metrics.
- **Vercel & Next.js 14 App Router Ready**: Statically optimized production build with clean URLs, sitemap, and SEO tags.

## ⚙️ Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/surazraaz1998/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build production bundle**:
   ```bash
   npm run build
   ```

5. **Start production server**:
   ```bash
   npm run start
   ```

## 🌐 Deploying to Vercel

This repository is pre-configured for 1-click deployment on **Vercel**:

1. Push your changes to GitHub:
   ```bash
   git add .
   git commit -m "Prepare Vercel deployment & update structure"
   git push origin main
   ```

2. Import your GitHub repository on [Vercel](https://vercel.com/new).
3. Vercel automatically detects Next.js framework settings. Click **Deploy**.
